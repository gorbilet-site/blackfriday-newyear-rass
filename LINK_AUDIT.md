# Проверка ссылок и фотографий — 4 ноября 2026

Проверен проект из `novyj-god-v-novom-gorode-nextjs.zip`. Изменения ограничены фотографиями, разметкой фактической московской ссылки и средствами сборки/проверки.

## UTM

Для 12 экскурсий, 6 туров и 2 городских переходов проверены:

- `utm_source=vk`
- `utm_medium=rassilka_tr`
- `utm_campaign=moscow_newyear_<город>`: `kaliningrad`, `kazan`, `nn`, `moscow`, `spb`
- `utm_content` — последний сегмент пути страницы предложения.

У туров из Петербурга город кампании — `spb`, включая тур в Москву. Все шесть адресов из задания присутствуют без замены.
В присланном примере другие medium/campaign (`rassilka_teatr`, `spektakl_spb`); использованы явно заданные для этой рассылки `rassilka_tr` и `moscow_newyear_<город>`.

Московская ссылка подключена к опубликованным «Огням Москвы»: `https://gorbilet-site.github.io/ogni-moskvy/?utm_source=vk&utm_medium=rassilka_tr&utm_campaign=moscow_newyear_moscow&utm_content=ogni-moskvy`.
Для корневого адреса петербургского сайта сохранён явно заданный идентификатор `black-friday-gorbilet`: у такого URL нет сегмента пути.
Полные готовые адреса находятся в `link-audit.csv`.

## Подключение лид-магнитов

**Москва:** в `src/data/cities.ts` установлен `leadUrl: "https://gorbilet-site.github.io/ogni-moskvy/"`. Московское предложение и ссылка в подвале используют общую функцию `leadHref`, добавляющую разметку новогоднего лендинга для всех городов. Запасной переход на общую московскую афишу больше не используется для этих кнопок.

По последующему указанию пользователя общие кнопки «На Горбилет» в шапке, «Все билеты на Горбилете» в мобильном меню и «Все скидки на Горбилете» в подвале размечены: `utm_source=vk`, `utm_medium=rassilka_tr`, `utm_campaign=other_newyear_tr`, `utm_content=home`. Для корневого адреса без сегмента пути используется `home`.

Ссылка на `https://www.black-friday-gorbilet.ru/` и `https://vk.me/gorbilet` присутствуют и ответили HTTP 200. Московский запасной адрес также ответил HTTP 200.

## Фотографии

Добавлено 18 фотографий: 12 экскурсий и 6 туров. Каждая взята из галереи именно соответствующего предложения, по совпадению его slug, без картинок из рекомендаций.
Все 18 страниц ответили HTTP 200, содержали активное предложение с доступными датами на момент проверки. Это не проверка процесса оплаты или наличия мест на каждую дату.
Адреса страниц и исходных фотографий сохранены в `src/data/offer-photos.json`; локальные WebP — в `public/offers/`.
Файлы уменьшены до области 900 × 600 пикселей; суммарный размер — около 1,75 МБ. HTML содержит фотографии внутри файла.

## Проверки

- `node scripts/check-links.mjs`: 21 уникальный размеченный адрес, точные UTM, отсутствие дублирующихся меток, все 6 туров, 18 локальных фотографий — успешно. Общий адрес используется тремя кнопками.
- TypeScript — успешно.
- Однофайловый HTML — успешно.
- Статический экспорт Next.js: `STATIC_EXPORT=1 next build --webpack` — успешно. Добавлен резервный скрипт `build:webpack`, поскольку Turbopack в текущей Windows-среде завершался при обработке CSS.
